# Garden

Lightweight maintenance pass for a single company's GBrain runtime.

```bash
core/scripts/hq-gbrain status <company>
core/scripts/hq-gbrain doctor <company>
core/scripts/hq-gbrain search <company> "<company-specific term>"
```

Write a report to `workspace/reports/gbrain/` with:

- Runtime status
- Import coverage signal
- Search smoke result
- Missing setup or model configuration
- Recommended next action
