# Practice client: Northwind Labs

Northwind Labs is invented. Use it to try /client-onboarding before you run it
on a real client. Nothing here is real data.

| File | What it is |
|---|---|
| contract.md | Signed statement of work |
| proposal.md | The accepted proposal |
| sales-call-transcript.md | The sales call |
| campaign-export.csv | Q3 ad campaign export |
| crm-outcomes.csv | CRM leads and opportunities by source and company size |
| landing-page.md | Text of the page the ads send traffic to |

## For instructors: what a good run should catch

Do not show this section to students before they run the practice. A good run of
/client-onboarding should surface at least these:

1. **Brands.** The call discusses three products (Cloud, Edge, Academy). The
   contract covers Cloud only and excludes the others. Edge already has spend.
2. **Proposal vs contract.** The proposal recommends a landing page refresh. The
   contract excludes landing page work.
3. **Goal vs optimization.** The goal is 25 enterprise sales-qualified
   opportunities. Every campaign optimizes for any form submission.
4. **Where the money goes.** Free Trial search is 46% of spend and produced 0
   enterprise opportunities in September. Enterprise search and LinkedIn
   produced 7 of the 11 enterprise opportunities.
5. **Data limits.** CRM data covers September only (July and August were lost in
   a migration), and one month is too short to judge closed revenue. The audit
   should say so rather than project it.
6. **Missing inputs.** No approver is named (the CEO may also want sign-off),
   LinkedIn access is pending, no brand guidelines were supplied, and there is no
   CRM access for the agency.
7. **Landing page.** No demo path for enterprise visitors, which limits any
   campaign change, and fixing it is out of scope.
8. **Mismatched periods.** Spend is a Q3 total; CRM outcomes are September only.
   A cost per opportunity calculated by dividing one by the other is wrong. The
   audit should refuse it and ask for September spend by campaign. The contract's
   access deadline (5 business days after 2026-09-22) has also passed with
   LinkedIn access still pending.
