# More workflows

Load when the user asks for one of these chains, or when the table in SKILL.md doesn't
cover the request. Same rules as SKILL.md: plan first for 3+ steps, parallel where the
steps don't depend on each other, times are wall-clock.

### Start a Newsletter
```
/newsletter (format + first edition)
→ (parallel: /lead-magnet opt-in incentive + /email-sequences welcome)
→ /content-atomizer launch promotion
```
~25-35 min.

### Get Cited by AI ("am I in ChatGPT or AI Overviews?")
```
/ai-search (share-of-model audit)
→ /seo-content refresh mode (fixes on the pages the audit flags)
→ the citation-monitor routine (automations/)
```
~20-30 min for the audit and first fixes. Citation sets churn month to month, so
monitoring is recurring by design (rates in /ai-search's references/aeo-facts.md).

### Monthly Review ("how's it going")
```
/performance-review (real numbers in) → routed fixes
```
The review writes priors to learnings.md and returns 3-5 ranked actions already mapped
to skills. ~15-25 min plus the fixes. For a local business with ads, add
/ads-incrementality-check once a quarter or after a big budget change.

### Programmatic SEO ("a page for every X")
```
/keyword-research (validate the pattern and the modifier set) → /programmatic-seo
```
Validating the pattern is cheap insurance before generating 200 pages. ~30-45 min. A
local business wanting a page per town goes to /local-seo-plan then /service-area-pages
instead: towns need real local proof, not a data column.

### Local launch (a new location or a new service)
```
/google-business-profile (profile + first month of posts)
→ (parallel: /service-area-pages for the new town or service + /reviews ask set up)
→ /paid-ads (small, one broad campaign) with /google-ads-tracking first if calls aren't counted
```
~45-60 min.

### Agency onboarding (a signed client)
```
new client <url> (lite read into ./brands/<slug>/)
→ the client's first move from the lite report
→ "deep" when the retainer covers strategy work
```
~3 min, then the first fix.
